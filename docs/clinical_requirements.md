# 脑萎缩定量分析平台 — 需求分析文档

## 1. 临床场景定位

**目标场景**：神经内科门诊的脑萎缩 / 阿尔茨海默早期辅助筛查

**核心痛点**：
- 医生肉眼评估 MRI 脑萎缩程度主观性强，不同医师间一致性差
- 缺乏定量指标（体积、比值），难以追踪病程进展
- 现有工具（FreeSurfer、FSL）部署复杂、耗时长，不适合门诊快速筛查
- 基层医院缺乏神经影像定量分析能力

## 2. 目标用户画像

### 2.1 主要用户：神经内科医师（门诊/住院部）
- **工作流**：接诊认知障碍主诉患者 → 开 MRI → 读片 → 结合临床评估 → 诊断
- **需求**：快速获取脑萎缩定量指标，辅助判断是否建议进一步检查（如 PET、腰穿）
- **使用场景**：门诊读片间隙，2-3 分钟内完成一次分析

### 2.2 次要用户：放射科医师
- **工作流**：阅片 → 写报告 → 签发
- **需求**：在报告中引用定量数据，提升报告客观性

### 2.3 潜在用户：体检中心 / 基层医疗机构
- **需求**：低成本、易部署的筛查工具，无需专业影像科医师

## 6. 用户故事

### US-01: 门诊快速筛查
> 作为神经内科医师，我希望在门诊读片时上传患者 MRI，3 秒内获得脑萎缩定量报告，以便快速判断是否需要进一步检查。

**验收标准**：
- 上传 NIfTI 后 5 秒内显示定量指标和三视图
- 萎缩分级与医师目测结果一致性 ≥ 80%
- 报告可打印，包含患者 ID 和检查日期

### US-02: 放射科报告辅助
> 作为放射科医师，我希望在写报告时引用定量数据，提升报告客观性，减少主观描述。

**验收标准**：
- 报告包含 GM/WM/CSF 体积（mL）和 TIV 归一化比值
- 萎缩分级有明确的参考范围和解释
- 支持导出为 PDF 或复制到报告系统

### US-03: 基层筛查
> 作为社区卫生服务中心医生，我希望用低配置电脑也能运行分析，以便开展老年认知障碍筛查。

**验收标准**：
- CPU 模式下推理时间 < 30 秒
- 支持 DICOM 格式（直接从 CT/MRI 设备导出）
- 界面简洁，无需专业培训

## 7. 风险与限制

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 模型仅在 IBSR-18 上训练 | 泛化性存疑 | 补充 OASIS/ADNI 验证 |
| 去颅骨依赖外部工具 | 若输入未去颅骨，分割可能失败 | 添加质量控制检查，提示用户预处理 |
| 3 分类粒度不足 | 无法单独评估海马体 | 后续引入多标签模型 |
| 单中心数据 | 可能存在扫描仪偏差 | 跨数据集验证 + 数据增强 |
| 无临床验证 | 无法作为诊断依据 | 明确标注"仅供辅助参考" |

## 8. 跨数据集验证计划

### 8.1 验证数据集
- **OASIS-1**：416 例，含 AD 患者和正常对照，T1 MRI + CDR 评分
- **ADNI**：多中心纵向数据，含 MCI/AD 患者
- **IXI**：600 例健康成人，多中心扫描仪

### 8.2 验证指标
- Dice 系数（CSF/GM/WM）
- 体积测量误差（与 FreeSurfer / FSL 对比）
- 萎缩分级一致性（与医师评分对比）

### 8.3 执行步骤
1. 下载 OASIS-1 数据（需注册）
2. 预处理：去颅骨 → NIfTI
3. 运行推理，生成分割结果
4. 计算与公开标注的 Dice
5. 对比体积测量与 FreeSurfer 结果
6. 撰写验证报告
